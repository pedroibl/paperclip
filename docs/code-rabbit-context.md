## Overview
CodeRabbit is an AI code review tool for pull requests (PRs), IDE extensions, CLI. Features:
- PR summaries, walkthroughs, CI/CD analysis, slop detection.
- Pre-merge checks, autofix, unit tests, docstrings, merge conflict resolution.
- Issue management (validation, creation, enrichment).
- Configurable (YAML, repo/org settings, path/AST instructions, knowledge base).
- Platforms: GitHub, GitLab, Bitbucket, Azure DevOps.
- Pricing/contact: coderabbit.ai/pricing, discord.gg/coderabbit, github.com/coderabbitai.
